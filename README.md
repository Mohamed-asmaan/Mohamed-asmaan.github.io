# Pixel Echo

You are an award-winning creative frontend developer and interaction designer.

Build a personal portfolio that feels like a futuristic operating system running on a vintage CRT monitor.

DO NOT clone or recreate any existing portfolio.

Instead, capture the overall atmosphere while creating something original and premium.

The design philosophy is:

Retro Computing

+

Modern Apple-level Minimalism

+

High-end Motion Design

+

Experimental Creative Portfolio

Think:

• CRT monitor

• phosphor glow

• monochrome terminal

• brutalist typography

• cinematic transitions

• modern interaction design

• premium animations

The site should NOT look old.

It should look like someone rebuilt a 1980 terminal interface using 2035 web technology.
